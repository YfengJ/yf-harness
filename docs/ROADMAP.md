# Roadmap

## 0.1：本地第一版

Provider/事件、Agent Loop、安全工具、SQLite、TUI/CLI、上下文、观测、Replay、离线 Eval 与发布质量门。

## 0.2：兼容性与可靠性

- LangChain、LlamaIndex、AutoGen 可选原生 Agent 适配层，含离线与 OpenAI-compatible 契约测试。（已完成）
- 更多经过契约测试的 OpenAI 兼容 SSE 变体。
- Windows 子进程树和文件替换专项加固。
- 可插拔 tokenizer 与更细粒度成本预算。
- Trace/Eval 差异比较和失败最小化。

## 0.3：受控扩展

- Provider/Tool 插件发现与版本化能力协商。
- 可选 OS 沙箱后端和网络 allowlist。
- 会话分支、可移植加密导出与恢复工具。
- TUI 可访问性、主题和大型历史性能优化。
- 经过安全设计评审后，探索把只读工具以受控代理方式暴露给框架，而非直接授予执行权。

## 0.4：项目智能与桌面工作流

- 跨 `AGENTS.md`、`CLAUDE.md`、Cursor Rules 与 YF-Harness 的分层项目指令。（已完成）
- Git 感知本地项目索引、可解释上下文、运行中任务队列与 Plan→Execute。（已完成）
- 会话分支、逐文件 Diff 审查和哈希冲突安全恢复。（已完成）

## 0.5：工作流扩展与性能

- 版本化工作流 Profile、工具 allowlist 与可审计 Pre/Post hooks。
- 多模态附件和 MCP/插件能力协商，上传与权限边界必须显式可见。
- 可选隔离研究任务，禁止共享隐式可变状态或直接合并冲突修改。
- 裁剪 macOS App 未使用的 Qt 模块，并为项目索引增加增量缓存和性能基线。

## 0.6：可信技能与恢复

- 跨 Codex、Claude Code、Cursor 的 workspace 项目技能与命令兼容。（已完成）
- 桌面 `$` 命令面板、来源可见性与显式调用。（已完成）
- 按运行整组哈希预检与冲突安全恢复。（已完成）
- 后续探索可持久化的运行队列；必须先定义崩溃恢复和附件生命周期。

## 0.7：桌面精密编辑台

- 对话优先的原生桌面骨架、紧凑任务导航和编辑稿式消息流。（已完成）
- 运行、上下文和变更控制台按需展开，保留完整安全与审查功能。（已完成）
- Composer、空状态、键盘路径和真实 Bundle 截图回归。（已完成）

## 0.8：Composer 工作流控制

- 输入框内 Agent/Plan 快速切换与当前 Provider 模型选择。（已完成）
- 会话级 `/goal` 创建、恢复、完成、清除与安全上下文注入。（已完成）
- 真实 ContextSnapshot 百分比、Token 预算、来源和压缩状态概览。（已完成）

## 0.9：蓝图工作室

- 全新暖白/海军蓝桌面视觉系统与可见键盘焦点。（已完成）
- 三层响应式 Composer、任务状态带和覆盖式检查器。（已完成）
- `⌘/Ctrl+K` 命令中心与 7 个高频工作流入口。（已完成）
- 1040×720、1280×800、1480×824 长文本压力截图与几何回归。（已完成）

## 0.11：安静的对话工作台

- 空会话压缩为一句引导，Composer 只保留附件、输入与发送。（已完成）
- 模型、模式、上下文和本地用量迁入左下角“设置与用量”入口。（已完成）
- 统一 `+` 支持图片与受安全边界保护的 UTF-8 普通文件上下文。（已完成）

## 非目标

模型训练、云端账户、分布式多 Agent、远程任意执行、通用浏览器自动化和大型 RAG 不进入近期路线。新功能必须先说明威胁模型、迁移、离线测试和退出路径。

## 我应该理解什么

Roadmap 表达优先级和约束，不是发布日期承诺。

## 我可以修改什么来做实验

为一个 0.2 条目写最小 RFC，包含验收和回滚方案。

## 常见 Bug

先加入插件系统再定义契约、功能膨胀越过安全边界、没有迁移策略。

## 面试可能如何提问

如何决定 Agent 产品下一步做什么？如何控制技术债和范围？

## 一个动手练习
