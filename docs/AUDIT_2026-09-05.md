## 安全审查与残余风险

- Gitleaks 8.30.1 下载校验通过，基线全部 40 个提交无密钥命中；发布时再扫描最终暂存树和完整历史。自动扫描不保证识别任意格式秘密，也不等于独立渗透测试。
- pip-audit 2.10.1 扫描全部 extras：只剩可选 NLTK 3.10.3 的一个已知未修复公告，详情与 2026-10-05 到期策略见 [SECURITY.md](../SECURITY.md)。核心/桌面不依赖它。
- Bandit 无 HIGH；两处 MEDIUM SQL 提示复核为固定条件/参数占位符的动态拼接，值仍绑定参数；另一个 MEDIUM 是显式审批的 Shell 入口。LOW 主要是类型断言和预期 subprocess；未把扫描 exit 1 报告成零问题。
- Change Radar 自动结果为 P0/100，主要由 `SECURITY.md`、安全 CI、依赖和多模块变更规则累计触发，`blocking_gaps=[]`；人工按跨契约高风险 P1 执行完整门禁，未绕过风险门槛。
- 应用不是强沙箱；已批准 Shell/MCP 可使用当前用户权限。路径复核仍有极小 TOCTOU 窗口；复杂 Windows 进程树清理有平台限制。PID 复用采取保守策略，可能暂留陈旧运行状态而不误杀活跃任务。
- MCP 准备期间的取消会在 Runner 注册后生效，不保证第三方进程启动的即时中断。真实网络调用依赖用户凭据与服务可用性；本轮不冒充完成有费用 API、真实 Brave 查询或所有第三方服务端验收。
- macOS App 为本机 ad-hoc 签名构建，不是 Developer ID 已公证分发包。
