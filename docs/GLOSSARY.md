# 术语表

- **Harness**：掌握上下文、模型请求、工具执行、策略、存储与观测的宿主系统。
- **Provider**：把某种模型 API 适配为统一事件流的端口实现。
- **ModelEvent**：文本、工具调用、用量、完成或错误等规范化事件。
- **Agent Loop**：模型与受控工具交替执行直到终态的显式状态机。
- **Tool Schema**：工具输入的机器可验证结构；它不是授权规则。
- **Policy**：由模式、权限和风险计算允许、审批或拒绝的规则。
- **Approval**：副作用执行前的人类决定和审计记录。
- **WorkspaceGuard**：真实路径和符号链接边界检查。
- **Context Snapshot**：一次模型请求实际使用的指令、消息、文件和预算记录。
- **Compaction**：把旧历史压成结构化任务状态的过程。
- **Trace**：请求、事件、工具、审批、用量和上下文的关联记录。
- **Replay**：读取既有 Trace 重现过程；默认不重复副作用。
- **Eval**：以场景和评分验证完整 Agent 行为的离线评测。
- **SSE**：服务端事件流，OpenAI 兼容服务常用的增量传输格式。

## 我应该理解什么

同名词在边界中的精确定义，特别是 Schema、Policy 和 Approval 的区别。

## 常见 Bug
